## 🛠️ Featured Projects

### 1. 🏥 HealthFit: End-to-End Health Analytics
A comprehensive system that bridges the gap between medical diagnostics and wellness.
- **Problem Solved:** Making medical reports easy to understand for common users.
- **Key Features:** Automated medical report analysis, disease prediction, personalized diet plans, and exercise suggestions.
- **Tech Stack:** Python, Pandas, Scikit-Learn, Flask/Streamlit.

### 2. 🚗 AI Accident Detection & Driver Safety
A real-time safety solution to reduce road fatalities using Computer Vision.
- **Key Features:** Detects driver drowsiness via eye-tracking and identifies collisions using YOLO.
- **Emergency Logic:** Automatically sends accident location coordinates via Twilio & Google Maps API.
- **Tech Stack:** YOLO, OpenCV, Python, Twilio API, Google Maps API.

### 3. 📚 Smart RFID Library Assistant
Modernizing library operations using a blend of hardware and intelligent software.
- **Key Features:** Secure RFID-based book issue/return and a hybrid recommendation engine that suggests books based on student interests.
- **Tech Stack:** Arduino, RFID RC522, Python, SQL, Hybrid Filtering.

### 4. 🎬 Movie Recommendation Engine
A personalized content discovery platform.
- **Logic:** Uses Collaborative and Content-based filtering to predict user ratings and suggest movies.
- **Tech Stack:** Python, NumPy, Scikit-Learn, Streamlit.
